# 业务建议

> 结构说明：建议**不按想法罗列，按用户旅程排列**——用户从发现产品到赎回，每一步对应一个发现、一个改动。  
> 每条建议固定四件事：**依据哪个发现 → 具体改什么 → 怎么衡量（指标）→ 优先级**。  
> 少了"依据"，建议就是拍脑袋；少了"指标"，建议就是空话。【改】标记同前，是你的部分。

---

## 一、先说清楚：这套建议的立场

我们发现的问题是**信息不对称**：平台掌握费率档位、同类排名、回撤分布这些数据，  
但用户在购买页上只能看到"近一年涨幅"和一行小字费率。  
所以整套建议的共同逻辑只有一句话：

> **把事后才能看到的信息，挪到事前。**

不涉及改产品、改费率结构（那是基金公司的事），只改**信息的呈现位置和呈现方式**。  
这也是为什么这套建议对平台是可执行的——改的是前端展示层，不动交易和产品库。

## 二、五条建议（按用户旅程排序）

### 建议 1｜发现环节：给产品打「体检标签」，搜索与推荐降权

- **依据**：图 6——1097 只产品（21.6%）收着标准档以上费率、卡玛却在组内后 25%，费后年化比同类低 13.07 个点。
- **改什么**：用本项目的打分结果给每只产品生成一个"同类体检分"（同类型内 0–100 分位），标签三档：健康 / 一般 / 需注意。"需注意"产品在搜索结果和推荐流里**不删、不下架，但降权并展示标签**。
- **怎么衡量**：被标"需注意"产品的点击率、买入转化率变化；被降权产品买入用户的后续持有人收益率是否改善。
- **优先级**：⭐⭐⭐（直接命中项目核心结论）
- **为什么不直接下架**：平台与基金公司有代销协议，直接下架有商业和合规冲突；降权 + 标注是"披露但不替代决策"，既保护用户又守住合作关系。

### 建议 2｜比较环节：费率从"一行小字"升级为独立维度

- **依据**：图 2（58% 产品费率都是 1.40% 档，用户根本无从比较）+ 图 5（费率档位与卡玛单调负相关，最便宜档性价比是最贵档 5.7 倍）+ 图 3（费率与收益相关系数仅 0.05，多付的钱买不到业绩）。
- **改什么**：① 详情页标注"你的费率属于哪一档"（0.2 / 0.6 / 1.4）；② 排序器新增"费后收益"选项；③ 同类对比页默认展示"同价位档内排名"。
- **怎么衡量**：使用费后收益排序的用户占比；点击费率档位说明的用户后续持有的产品费率是否下降。
- **优先级**：⭐⭐⭐（三张图共同支撑，证据链最全）

### 建议 3｜买入环节：购买确认页放"历史回测曲线"

- **依据**：图 8——同样 1 万元，白酒指数C三年剩 5,400，沪深300联接变 11,800；以及图 7——被套的是"高点卖出的赛道产品"。
- **改什么**：用户点"买入"前的确认页，展示该产品"如果三年前买入"的净值曲线，并在赛道指数处于历史高位时追加时点提示（"该主题上一轮高点的最大回撤是 49.5%"）。
- **怎么衡量**：确认页展示后的下单放弃率变化；新买入用户的平均建仓成本相对赛道位置。
- **优先级**：⭐⭐（转化率可能受影响，需要 A/B 验证——**这一条要主动写明风险**：短期转化率下降换长期持有人收益，是平台的战略取舍）
-

### 建议 4｜持有环节：业绩展示用「中位数 + 亏损概率」替代单一涨幅

- **依据**：图 1——主动权益 23% 的产品三年亏损，但均值被右尾撑高（偏度 1.01）；涨幅榜天然只展示赢家。
- **改什么**：业绩区块固定两个数——"同类中位数收益"和"任意时点买入并持有三年不亏的概率"；经理变更时主动推送提示（业绩是谁挣的，未来是谁管的）。
- **怎么衡量**：用户的持有期是否变长（平均持有天数）、割肉率（低点卖出比例）。
- **优先级**：⭐⭐

### 建议 5｜选份额环节：A/C 份额费用对比器

- **依据**：step1 发现的份额问题——同一只基金 A 类收申购费、C 类收销售服务费，每年差 0.4%–0.8%，持有越久差距越大。用户买 C 类短线合理，买 C 类长期持有就是白花钱。
- **改什么**：同一基金存在多份额时，购买页强制展示"计划持有多久"的选择器，按持有期自动推荐更划算的份额（持有 <1.5 年选 C，≥1.5 年选 A，临界点用真实费率算）。
- **怎么衡量**：份额错配率（长期持有却买了 C 类的用户占比）下降幅度。
- **优先级**：⭐⭐（实现成本最低、争议最小的一条，适合作为排期第一名）

## 三、优先级矩阵（面试可直接画在白板上）

| 建议          | 用户价值 | 平台可行性        | 优先级 |
| ----------- | ---- | ------------ | --- |
| 1 体检标签降权    | 高    | 中（需处理商务关系）   | P0  |
| 2 费率维度升级    | 高    | 高（纯前端）       | P0  |
| 3 确认页回测曲线   | 高    | 低（伤转化，需 A/B） | P2  |
| 4 中位数+亏损概率  | 中    | 高            | P1  |
| 5 A/C 份额对比器 | 中    | 高（成本最低）      | P1  |

> 【改】面试必问的两问，先想好答案：  
> ① "平台为什么没做这些？"——短期转化率 vs 长期持有人收益的激励错位，你的建议本质是让长期指标可见；  
> ② "你怎么证明建议有效？"——不是"我觉得有用"，是每条都挂了可观测指标 + A/B 设计。

## 四、这套建议的局限（报告里要写）

- 衡量指标（持有期、割肉率）依赖平台内部数据，本项目只有公开数据，**只能证明问题存在，不能证明建议有效**——有效性要靠平台的 A/B 实验，这一点如实写。
- "高费低效"基于近 3 年单区间，2021 年那轮行情只覆盖了一半周期；时点提示（建议 3）的阈值设计需要跨周期数据校准。
- 所有建议基于"信息不对称"假设，**没有做用户访谈验证**——用户是否真的会看这些信息，是下一步要补的功课（这也是局限不是漏洞，写出来加分）。
