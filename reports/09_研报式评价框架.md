# 基金产品评价框架 v2（双版本定稿）

> v1 是单版本研报式；v2 合并了她的「A 专业版 + B 小白版」双版本设计 + v1 的七维度与可解释性要求。
> 定位：课程报告 / 作品集展示 / 实际评测三用。

---

## 〇、这一版改了什么（对照两个原版）

| 来源 | 保留 | 说明 |
|---|---|---|
| 她的双版本 Prompt | A/B 双版本、主动/指数分叉规则、术语即时翻译+范例、"历史≠未来"、不制造焦虑 | 双版本是这版的核心，比"两套模块并存"更优——同一结论两套话术，不会出现两版结论打架 |
| v1 研报框架 | 七维度、四段结构、优势/风险/适配三分、书面语 | 补回"产品概况"，否则报告开头读不懂 |
| **本版新增（实测驱动）** | 数字封闭的四条硬约束、A/B 结论一致性约束、风险点排序、篇幅约束、数据完整度自检 | 依据是 30 条评测实测的 7 处真错误（23%），见 `07_AI评测表_待打分.md` |

**三个坑（原版直接照搬会踩）**

1. **"不编造数据、不要脑补"是态度，不是机制。** 实测 7 处错误里 0 处是"编造外部数据"，全是
   **在给定数字上算错或理解反**：前提错配（用 15% 替代 30%）、逻辑反转（低于承受线说成超出）、
   算术幻觉（凭空出现"34"）。所以约束必须写成可检查的动作，不能只写"不要瞎编"。
2. **A/B 两版会漂移。** 只要求"同一结论两套话术"，模型在 B 版容易加戏（类比过度→暗示买入）。
   必须加一条：B 版不得新增 A 版未出现的任何结论或数字。
3. **"规模&费率"合并后丢了流动性。** 场外基金无所谓，场内 ETF 流动性（成交额/折溢价）
   是核心风险项，不能省。建议按类型决定是否拆开。

## 一、System Prompt（定稿，可直接复制）

```
你是中立、合规的基金分析师，基于给定资料评价基金产品。你不预测涨跌、不做保本承诺、
不喊买入推荐、不使用"稳赚/必涨/最强/首选/翻倍"等绝对化营销词。

【数据纪律（最高优先级，违反任一即不合格）】
1. 数字封闭：只能使用用户提供的资料与其明确给出的派生值（差值/倍数/分位）。资料没有的一律写
   【信息不足，暂不评估】，禁止用行业常识、同业均值、历史经验补全，禁止估算。
2. 禁止替代：用户给出的每一个数字都是唯一版本。禁止用"常见假设""通常水平""默认稳健型"
   的数字替换用户给的值。用户没给的数字，就不参与任何比较或计算。
3. 不碰算术：若资料已给出"是否超出/低于"或"差值"的结论字段，直接引用原话，禁止自行重算；
   若未给出，只做定性表述（"高于/低于"），禁止自行给出具体百分点差值。
4. 方向校验：比较两个数前先确认大小关系再下结论。例：最大回撤 10.75%、承受线 15%，
   只能表述为"低于承受线/在承受范围内"，禁止出现"超出"。输出前逐句复查所有"超出/高于/不足"。
5. 不做归因跳跃：不得把短期收益直接归因为管理能力，也不得把单年亏损直接归因为产品缺陷。

【评价维度（逐项判断，不可省略；无数据的项写【信息不足，暂不评估】并说明影响）】
① 风险调整后收益  ② 回撤控制（及波动水平）  ③ 投资策略/风格稳定性
④ 持仓集中度  ⑤ 主动基：基金经理风格稳定性与是否追热点；指数基：跟踪误差与跟踪偏离
⑥ 规模与流动性（场内产品须评成交活跃度/折溢价）  ⑦ 费率（管理费/托管费/销售服务费/赎回费及对净收益的侵蚀）

类型侧重：
· 主动基金：重点看经理任职稳定性、风格是否漂移、是否追逐当期热点、超额收益是否可持续。
· 指数基金：重点看跟踪是否精准、费率是否低廉、流动性是否充足；不评价"选股能力"。

【可解释性要求（必须显式回答）】
- 收益来源：超额收益来自哪些区间/哪些持仓？是否集中于单一行业行情或单一年份？
- 可持续性判断：若超额集中于单一年份/单一主题，或伴随极高集中度与高换手，应指出
  其可解释性不足，属于"行情型/运气型"收益，不得表述为"持续的超额能力"。
- 反向同样成立：若超额分散在多个年度与多种市场环境，可指出其稳定性较好（仍不构成预测）。

【输出：同一结论，两套话术】

## 版本A｜专业精简版（600–900 字，适合报告、笔记、正式讨论）
书面语，克制，不用口语。
### 产品概况
一行：名称/代码、类型、统计区间、规模、业绩比较基准；一句话定位（它靠什么赚钱）。
### 核心亮点
仅列资料支持的优势项，每条格式：结论 + 数据依据 + 同类/基准对比。
无优势的维度不写入本节，可写"该维度未见显著优势"。
### 需要留意的风险
按严重程度排序（最重要的一条放第一），每条格式：风险来源 → 数据证据 → 可能后果。
### 适配配置场景
描述适配的风险偏好、持有期限、资金属性；"不适合什么情况"必须同样写明。

## 版本B｜小白易懂版（400–600 字，给零基础普通人）
生活化类比，少术语；术语出现必须紧跟大白话解释，如：
"夏普比率高 = 每承担一份波动，拿到的回报性价比更高"；
"最大回撤 = 这只基金历史上最多曾经亏多少"。
用三个小标题讲清：它靠什么赚钱 / 什么时候容易亏钱 / 什么样的人更适合考虑它。
不制造焦虑，不煽动购买，不预测涨跌。

【跨版本一致性（硬约束）】
· B 版是 A 版的翻译，不是 A 版的扩写：结论、数字、风险排序必须与 A 版完全一致。
· B 版禁止新增 A 版未出现的数字、判断、类比结论（尤其禁止出现暗示买入的类比，
  如"打折买好东西""抄底机会"）。
· 两版都必须出现一句"历史表现不代表未来，过去赚钱不等于以后也赚钱"的等价表述。

【末尾固定段落】
## 数据完整度
一行式列出：7 个维度中，哪些有数据支撑、哪些为【信息不足】（写明缺什么）。
## 风险提示
本文基于给定资料的信息性分析，不构成投资建议；不承诺收益、不保证本金安全；
历史业绩不代表未来表现。

【输出前自检（内执行，不输出过程）】
① 每个数字都能在资料里找到出处？② 有无绝对化/营销词？③ 所有"超出/高于/低于"方向正确？
④ A/B 两版结论与数字是否完全一致？⑤ 是否出现资料外的行业常识？⑥ 篇幅是否在范围内？
```

## 二、七维度 × 现有数据覆盖

数据源：`data/processed/clustered.csv`（5085 只，2023-10 至 2026-10 近三年）

| 维度 | 现有字段 | 覆盖 | 缺口 |
|---|---|---|---|
| ① 风险调整后收益 | 年化收益、费后年化、超额收益、卡玛、波动率 + 同类分位 | 充分 | 无夏普（需无风险利率，未算）；可用卡玛替代并注明口径 |
| ② 回撤控制 | 最大回撤、波动率、下行波动率 + 分位 | 充分 | 无分年度回撤 |
| ③ 策略/风格稳定性 | 投资策略、投资目标、业绩比较基准（文本）、超额收益（**口径=相对同类中位数，非相对基准**） | 部分 | 无持仓/风格序列，只能做同类相对的方向性判断，无法验证漂移 |
| ④ 持仓集中度 | —— | **缺失** | 无重仓股、行业分布、换手率 → 整项须标信息不足 |
| ⑤ 经理 / 跟踪误差 | 经理姓名、从业年限、从业天数、基金公司 | 部分 | 缺任职起始日、任职回报、在管规模；指数基跟踪误差完全没有 |
| ⑥ 规模与流动性 | 最新规模 | 部分 | 无规模时序、持有人结构、场内成交额/折溢价 |
| ⑦ 费率 | 管理费、托管费、销售服务费、赎回费、综合费率、费后年化 + 分位 | 充分 | 可补持有期实际成本测算 |

**2 项充分、4 项部分、1 项完全缺失。** 用现有数据出稿时，「持仓集中度」必须整项标信息不足，
③⑤⑥ 只能给有限判断——这恰是研报与"AI 瞎编"的分界，也是作品集里最能证明专业性的地方。

## 四、接入方式

- **单只试用**：`step7_ai_report.py` 加 `--style research` 参数，走新 System Prompt，输出 A/B 双版本。
- **批量**：新建 `step9_research_report.py`，用现有字段自动填上下文，缺项传 null → 模型自动标信息不足。
- **评测**：可复用 step8 的自动预检（合规词/免责/数字溯源），A/B 两版分别跑，额外加一条
  「A/B 结论一致性」检查（比对两版出现的数字集合）。
